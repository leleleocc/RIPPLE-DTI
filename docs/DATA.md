## 2. 阶段一：沿用基础数据

不再介绍五个来源。沿用已有测量、位点、序列和编号对应，统一构建“小分子 + 蛋白序列 + 三维参考结构”的输入。

- Kd、Ki、IC50、EC50 分终点保留，不混成一个答案；保留单位、关系符号、实验条件和引用。
- 相互作用二分类只使用可追溯的实验规则；没有测量的组合不能当阴性。
- 口袋从独立参考结构生成；已知配体接触残基只作训练答案，不能参与预测候选口袋的生成。
- 残基是蛋白的一部分，在程序中是带坐标的节点；mask 只标记输入或标签是否有效，缺失答案不参与损失。
- 保存序列位置、结构链、作者编号和插入码之间的对应；部分映射不能冒充完整接触集合。
- 催化、跨膜和其他位置注释保留作分析；第一版独立功能残基分类关闭，`L_function=0`。

## 3. 阶段二：通道药理与结构

### 药理：教模型区分增强和抑制

来源为 **GtoPdb 2026.3.1，发布于 2026-10-12**，普查日期 2026-10-17。以下为已记录的历史统计，普查原料、报告和过程脚本已从本机清理。例如“某分子增强某物种通道的功能”提供增强标签；抑制包含阻塞等情况，不能直接解释为促进关闭。

| 筛选步骤 | 数量 |
|---|---:|
| 通道目录 `lgic/vgic/other_ic`，排除直接 PIEZO1/2 | 290 个靶点、31 个家族；3,170 条作用记录 |
| 小分子类型、有引用、有蛋白身份、非空 SMILES | 1,656 条 |
| 可映射为增强 / 抑制 | 1,621 条 |
| 删除 5 个作用冲突组合 | 1,611 条，合并为 1,551 组 |
| 再排除多 accession 组合和 Aquaporins | **1,525 组，1,583 条来源记录** |

首版候选包含 **596 组增强、929 组抑制；823 个药物 ID、172 个目录靶点、279 个物种特异 accession**。其中 **1,136 组**的蛋白有实验 PDB 命中，不保证完整装配或实验构建体匹配。

分组键为 `Ligand ID + Target ID + Target Species`。823 不是化学标准化后的独立分子数；该次普查**未执行 RDKit 校验**，不能解释为全部分子有效。

后续需要化学标准化、重新去重、实验条件与引用核验。仅有结合、方向不明或证据冲突的记录不进入功能损失；单 accession 记录也需检查是否代表多亚基实验系统。增强 / 抑制是在有作用证据的样本上学习的方向，不是“有活性 / 无活性”。

### 结构：辅助模型学习已有三维结构

同一目录的人、大鼠和小鼠共 750 个 accession 用于 RCSB 检索，截止 2026-10-17：

| 统计 | 数量 |
|---|---:|
| 不重复实验 PDB / polymer entity | **3,238 / 3,971** |
| 有结构命中的 accession / 目录靶点 / 家族 | **296 / 198 / 29** |
| 至少有两个结构的 accession | **250** |

这些条目含片段、辅助亚基、突变体和重复结构，尚未逐个审核坐标。**250 个蛋白有多个结构，不等于有 250 对药物响应样本。** 配对尚未审核，并非已证明没有响应对；本次普查的本机查询和报告已清理。

从 train 蛋白组中选择最多 1,000 个合格生物学装配，保留链、物种、构建体和突变身份；近重复先去重。计划每个结构固定抽取至多 64 个局部或跨亚基残基对，用当前 C-alpha 距离作答案；通用查询生成仍待实现。

这个辅助任务重建输入参考结构中的几何，不证明药物使结构发生了变化。首版药物结构响应、开关方向和状态偏好标签使用量均为 **0**；细分机制、pose 排序也关闭。

### 历史试点的边界

2026-10-16 的试点仅含 TRPV1、P2X3、GlyR 三类通道的 **8 个结构、16 个当前几何值、5 对结构的 10 个差值**。共配体、突变、物种与构建体差异使这些差值不能自动成为药物响应标签；它们也不是孔径或导电能力。

历史药理准备有 103 条记录，得到 58 条作用标签、42 条机制标签，二者重叠且未逐条匹配八结构。它们没有用于当时的几何优化，42 条机制标签在首版停用。

ARM64 Mac CPU、2 线程、隐藏维度 32、氨基酸身份特征下做过 64 次几何更新：训练 MAE 从 10.724 降至 2.935 Angstrom，**只评估同一批训练结构，无独立测试集**。另一次 `5SVJ + ATP` 完整前向 / 反向没有优化器更新；药理、响应、开关和偏好监督均为 0。这只能证明小规模流程能运行，不能当作正式模型效果或可用完整模型。

## 4. 清洗、划分与交付

1. 校验化学身份、完整序列、物种、实验构建体、突变和残基映射；保留来源版本、引用、哈希及每步排除原因。
2. 两阶段一起按完整序列分组：30% identity、双向至少 80% 覆盖聚类，并合并同一基因的物种同源物；记录工具及版本。
3. 按蛋白组约 80/10/10 划分 train / validation / test，再从 train 取预算；同组所有结构、状态、构建体和重复记录留在一起。
4. 阶段二验证 / 测试蛋白不得进入阶段一监督训练或几何辅助。PIEZO1/2 全家族及同源物单列 external，不参与训练、调参或阈值选择；当前普查仅排除直接目录项，完整同源审核待做。
5. 跨来源去重并报告药物骨架重叠。主协议为 cold-target，不能称为 cold-both；无测量不造阴性，无答案不补标签。
6. 分开保存输入有效 mask 和标签 mask；为每条样本记录蛋白、药物、参考结构、任务答案、证据、划分组及缓存路径。

最终交付固定来源清单、过滤统计、实际分任务样本数、跨阶段无泄漏报告、特征缓存和可执行加载入口。预算不足时使用真实合格数量。

本例已提供原始序列和坐标；全序列映射、构建体适用性、化学标准化、独立候选口袋、特征缓存和正式划分仍待完成，因此 JSON 不能直接送入当前训练器。未完成的字段保留 `null`。

### 几何样本：输入坐标，重建当前距离

以下采用 mmCIF 的作者链名和作者残基编号，坐标单位为 Angstrom。C-alpha 是用来代表一个残基位置的骨架原子。

| 残基 | 输入坐标 `[x, y, z]` |
|---|---|
| B 链 ILE 679 | `[-2.149, 4.685, -11.554]` |
| A 链 ILE 679 | `[-4.688, -2.141, -11.553]` |
| B 链 GLY 643 | `[-0.964, 3.656, -26.770]` |
| A 链 GLY 643 | `[-3.661, -0.958, -26.769]` |

输入完整参考结构和要查询的残基对，**输出答案分别为 B679-A679 的 7.282911、B643-A643 的 5.344418、B643-B679 的 15.296723 Angstrom**。三者都是同一结构直接计算的距离，不是三条独立结构样本、孔径或药物诱导变化。这条样本只启用 `geometry_snapshot`，不需要小分子或药理答案。

编号必须保留对应：本文件作者 B 链对应 label A 链，作者 A 链对应 label B 链；作者残基 679 对应构建体 label 546。它们都不能直接当成张量的第 679 个节点。页面只展示四个残基，完整输入保留四条链。

坐标和距离来自保留的 mmCIF，文件来源和哈希记录在 Demo 中；用于提取数据的过程脚本已清理。

### 基础回放：沿用原来的输入和答案

真实数据取阶段一 train 清单，输入、终点定义和标签变换保持一致。例如一条 Kd 回归记录，输入药物、蛋白和 `endpoint=Kd`，输出原测量值；**仅作格式演示**，若值为 10 nM，转换为 mol/L 后是 `1e-8`，对应 pKd=8。此数值没有对应真实药物或实验，不能进入训练。

| 样本类型 | effect | geometry_snapshot | affinity | native_pocket |
|---|---|---|---|---|
| 本例药理记录 | 开 | 关 | 关 | 关 |
| 本例结构记录 | 关 | 开 | 关 | 关 |
| 本例回放格式 | 关 | 关 | 开 | 关 |

这里的开关表示该条样本参与哪些损失。输入有效 mask 则回答哪些残基、坐标或补齐位置可用；两类 mask 不混用。真实口袋回放只在有对应答案时开启 `native_pocket`，不补造标签。
