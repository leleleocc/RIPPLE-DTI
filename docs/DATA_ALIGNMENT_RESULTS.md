# 五个来源的数据对齐结果

2026-10-15，已完成全量身份和标签统计，并对 300 个已有结构的复合物做逐残基验证。
结论是数据规模足够继续做基础 DTI、口袋和功能位点的最小实验；剩余工作主要是结构覆盖、
特征计算和训练划分。这不表示新增的离子通道结构响应、门控方向和状态偏好已有完整监督。
项目背景见 [design.md](design.md)，后续新增通道数据见 [CHANNEL_EXTENSION.md](CHANNEL_EXTENSION.md)。

| 来源 | 本次结果 |
|---|---|
| BindingDB | 扫描 3,243,660 条原始记录；初筛得到 2,422,809 条精确亲和力测量，覆盖 8,893 个蛋白 |
| BioLiP | 扫描 989,058 个位点；初筛得到 259,918 个小分子结合位点，覆盖 16,788 个蛋白，其中 72,640 个位点带催化注释 |
| PDBbind | 扫描 19,037 个复合物；初筛得到 14,367 个带精确亲和力的复合物，覆盖 2,757 个蛋白 |
| UniProt | 43,676 条有效蛋白序列；981 条空内容记录已列出并从候选数据中排除 |
| SIFTS | 930,404 条区间记录用于身份对应；另下载 300 个 PDB 的逐残基 XML，用于验证 |

“初筛”不等于最终训练集。BindingDB 配体尚未全量做化学标准化，蛋白构建体和突变尚需检查，
候选口袋和模型特征还没生成，PIEZO 同源排除与冷启动划分也尚未做。
初筛中已排除直接 PIEZO1/2；多链 BindingDB 记录保留但暂不计入候选。

三份带配体数据在蛋白层面的共同候选靶点为 **1,149 个**。
不同来源不必逐条配齐，已有监督可分别使用。

## 残基能否对齐

从 PDBbind 与 BioLiP 的交集中，选择 300 个复合物，优先覆盖不同蛋白和带催化注释的样本。
这是用于验证流程的确定性子集，不是随机抽样，不能用其成功率代表全库。

- 300 个均取得 SIFTS 逐残基映射。
- 254 个复合物的配体接触残基全部映射成功，且氨基酸与 UniProt 一致。
- 45 个复合物存在部分接触残基缺失或不匹配；另 1 个配体结构未通过读取校验。
- 检查的 804 个 BioLiP 位点中，769 个结合残基集合完整对齐，756 个催化残基集合完整对齐。

失败和不完整记录均保留原因，未把部分映射冒充完整标签。
原始残基编号、插入码和 UniProt 编号的对应保存在独立表中。

## 具体缺什么

- UniProt：981 个 accession 缺有效序列，清单在 `data/processed/uniprot/missing_accessions.txt`。
- 实验结构：BindingDB 候选靶点中，3,636 个在当前 SIFTS 中无实验结构对应，需要查询 AlphaFold。
- BioLiP 结构：67,718 个候选 PDB 不在已下载的 PDBbind 包中，扩展到这些位点时需另取结构。
- 残基映射：全量候选涉及 86,755 个 PDB，目前验证并缓存了其中 300 个，其余检索清单已生成。
- 模型特征：正式残基嵌入、残基图、候选口袋和药物特征仍需计算；本次五源对齐没有开始训练。
  2026-10-16 的 Mac CPU 几何小规模检查属于独立通道样例，不是五源预训练。

下一步可先用已完整对齐的 254 个复合物生成候选口袋和特征，跑通最小训练流程，再扩量。
候选口袋必须来自独立的 apo/AlphaFold 结构，不能直接把接触残基标签作为模型输入。

全部输出位于 `data/processed/`。详细统计见该目录的 `DATA_REPORT.md` 和
`alignment_summary.json`；复现命令、表结构与处理口径见 [DATA_PREPARATION.md](DATA_PREPARATION.md)。
