首轮规模：几十万基础记录、约千组通道药理、最多千个合格通道装配；最终数量以审核划分后的清单为准。

## 已完成工作

1. **收集原料**：在服务器下载 BindingDB、BioLiP、GtoPdb，以及 UniProt、SIFTS、RCSB 参考数据；本地已有的 PDBbind 两个压缩包通过 SCP 传入。校验文件完整性，保留来源版本、URL 和哈希，详见 [下载记录](DOWNLOADS.md)。
2. **统一格式**：使用独立 CPU 环境、24 个工作进程，流式解析来源记录并缓存分子标准化结果。以 InChIKey 连接分子，以 accession + 物种连接蛋白；统一单位和终点，保留原始证据、缺失值、冲突及待审原因。
3. **核验结果**：检查表间引用、记录代码与输出哈希，本地和服务器均通过 26 项相关测试。统一处理前后对比确认，服务器 raw 的 7,472 个文件及目录清单、内容哈希、大小、修改时间、权限均未变化。

服务器产物位于 `/home/rifo/RIPPLE-DTI/data/processed/unified_v1/`：共 **13 张 Parquet 表、1,461,283 个标准化分子、47,245 条有完整序列的蛋白身份**。10,146 种化学输入未通过标准化，已保留失败原因；113 个来源化合物 ID 标记身份冲突。完整统计见 [统一格式](UNIFIED_DATA.md)。

GtoPdb 通道方向初筛保留 **1,619 条候选证据**，尚非独立药物–蛋白配对或可训练样本。当前所有来源记录均为 `trainable=False`、`split=null`；结构与证据审核、数据划分及训练缓存仍待完成，见 [后续待办](TODO.md)。正式训练尚未开始，历史小规模检查不代表已获得可用的 PIEZO 预测模型。
