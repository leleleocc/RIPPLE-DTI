## 工作线一：先让基础任务可正式训练

### 1. 固化样本和监督契约

- [x] 分来源保留观测值与缺失标签，提供独立损失掩码。
- [x] 分开保存 Kd、Ki、IC50、EC50 和删失关系。
- [x] 保留 PDB 链、作者残基号、插入码和 UniProt 对应关系。
- [ ] 完成 BindingDB 配体化学标准化与失败统计；核对构建体和突变。
- [ ] 固化活性阈值、可靠负例和重复测量聚合规则，保留 assay 与原始来源。
- [ ] 按 `site_type` 决定功能任务的标签与掩码，不能把所有未注释残基默认标成负例。
- [ ] 定义正式样本、结构、候选口袋、标签和状态对应的缓存版本。

验收：每个监督样本可追溯原始记录；缺失标签不变成负例；多个终点不混合。
当前的分来源 Parquet 表是中间表，不是已经完成的 `samples.parquet` 训练缓存。

### 2. 从小子集生成正式输入

- [ ] 从 254 个接触残基完整对齐的复合物中选定首批样本，并固定选择清单。
- [ ] 取得推理时可用的参考结构，完成结构质量与序列映射检查。
- [ ] 从 apo/AlphaFold 参考结构独立检测候选口袋；记录算法、参数和覆盖率。
- [ ] 用已知结合残基评价候选覆盖，生成 `native_pocket_index` 及其可用性掩码。
- [ ] 计算正式残基嵌入、残基图、配体 1D/2D 特征和可用构象。
- [ ] 实现 `build_cache.py`、`RIPPLEDataset` 和 `collate_ripple` 的真实缓存链路。

验收：实际缓存可生成 `RIPPLEBatch`；所有索引和掩码通过检查；候选口袋不读取测试
配体坐标。长蛋白与多亚基结构保留完整身份；裁剪规则不能依赖待预测的标签。
本地检查用的 21 维氨基酸编码和补齐的原子特征不能冒充正式预训练特征。

### 3. 完成划分与泄漏审计

- [ ] 按蛋白序列聚类建立 cold-target 协议，记录 30% 阈值及比对覆盖要求。
- [ ] 完成 PIEZO1/2 及同源蛋白排除，全部留在 external 集。
- [ ] 同一蛋白的所有构象、重复结构和配对记录保留在同一划分组。
- [ ] 审计跨来源重复、InChIKey 和 scaffold；明确各评测协议允许的重叠。
- [ ] 定义 cold-pocket 与同时限制靶点/口袋的 cold-both，固定阈值和评价单位。
- [ ] 将划分 ID、规则、版本与泄漏统计写入独立报告。

验收：训练入口只接受通过相应协议审计的划分。通道样例中的家族分组不能替代正式
序列聚类；直接排除两个 PIEZO accession 也不能替代同源排除。

### 4. 实现正式训练和基础评测

- [ ] 完成 `src/ripple/train.py` 的采样、优化、保存、恢复与阶段调度。
- [ ] 先用小子集跑通基础阶段，再决定扩大规模与 GPU 训练配置。
- [ ] 每个损失记录原始值、权重、`label_count` 和跳过原因。
- [ ] 完成 `src/ripple/evaluate.py`，按任务和亲和力终点分别评测。
- [ ] 固定消融：去口袋条件化、去 pose 调制、去传播、完整模型。
- [ ] 在需要对齐既有工作时，使用单独的 benchmark 协议比较 TAMR baseline。

验收：可恢复的正式 checkpoint、独立验证集/测试集指标、配置与运行环境均可追溯。
DTI 报 AUROC/AUPRC 等；亲和力按终点报误差与相关性；口袋报排序及残基覆盖；
功能位点按类型报残基级 AUPRC 和支持数。

## 工作线二：补齐通道响应监督

### 5. 在现有样例上建立证据表

- [x] 缓存 RCSB、SIFTS、GtoPdb 官方来源，并记录 URL、时间和哈希。
- [x] 恢复完整生物学装配，保留装配链与原始链的映射。
- [x] 区分关闭、开放、部分激活和脱敏状态，保留构建体与突变信息。
- [x] 生成结构几何和比较差值，保留比较有效性与响应排除原因。
- [ ] 逐条核对结构状态的文献证据、实验条件、共配体和干预方式。
- [ ] 整理配体、浓度、物种、构建体、电压/机械刺激、测量终点与引用。
- [ ] 明确区分孔道阻断、门控调节、一般电流抑制和未知机制。

验收：有可复核的配对清单和纳入理由，不能仅凭同一 accession 或药理名称赋予
状态偏好、促进打开或促进关闭标签。已有 58 条作用标签和 42 条机制标签的筛选结果，
也不意味着这些记录已与 8 个结构逐条匹配。

### 6. 决定响应标签的证据等级

| 标签 | 当前 | 后续纳入条件 |
|---|---|---|
| 当前结构几何 | 已有 16 个值 | 当前坐标、完整亚基及映射核对有效 |
| 结构比较 | 已有 10 个差值 | 对应地标一致，比较条件与构建体差异显式保留 |
| 配体相关结构响应 | 当前未作为强标签启用 | 核实干预与匹配条件；弱关联监督必须另设证据等级和掩码 |
| 门控方向 | 当前可用强标签为 0 | 功能实验证据能够区分门控变化与孔道阻断 |
| 状态偏好 | 当前可用强标签为 0 | 状态特异结合或适当的比较证据，不能复用普通亲和力 |

需明确决定：是否先用较弱的 apo/holo 关联监督开展响应试验，以及不同证据等级如何
进入损失。现有代码不会自动把结构差值转为配体因果标签。

### 7. 训练并验证新分支

- [ ] 在正式特征和协议上评估几何辅助任务，而不只看训练误差。
- [ ] 有可用响应标签后再启用 `geometry_response`；有相应证据再启用门控和状态偏好。
- [ ] 将 `structure`、`channel` 的阶段调度接入正式入口，按标签覆盖选择实际阶段。
- [ ] 按家族、状态、构建体与证据等级分别报结果，比较恒零变化等基线。
- [ ] 验证更换配体是否改变预测，并结合独立标签判断这种变化是否正确。

验收：预测目标和标签有一致的生物学含义，测试样本没有进入训练，且改善超过预先
约定的基线。模型对配体敏感或梯度非零，只能算实现检查，不能替代这个验收。

## PIEZO 外部案例

这是正式训练和泄漏审计之后的工作。届时可比较口袋排序、相关残基、几何变化及
有监督支持的作用方向，逐条标注文献一致、未验证或冲突。
候选状态比较不等于生成新状态；距离变化不等于门控速率；边通量不等于物理能量路径。

## 环境和可复现记录

目前只运行过本地 Mac CPU 小规模检查。正式实验的设备、显存、特征版本、耗时与
checkpoint 需要在实际运行时记录，不沿用本地检查的误差充当正式结果。
完整训练循环仍是占位实现，不要直接把 README 或旧文档里的接口示例当作可执行训练任务。

CrossDocked/CASF、ASD、疾病变异注释等仍属于后续辅助任务或评测扩展，当前不作为
跑通基础任务和通道数据契约的前置条件。增加这些来源时需单独说明标签用途与泄漏规则。
